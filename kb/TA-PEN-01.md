# முதியோர் ஓய்வூதியத் திட்டம் (Vriddhjan Pension Yojana)

மித்ரபூர் பிரதேசத்தின் மூத்த குடிமக்களுக்கு மாதாந்திர நிதி உதவி வழங்கும் திட்டம் இது (`GL-PEN-01` மற்றும் திருத்தம் `CIR-2026-01`).

## திட்டப் பலன்
* தகுதியான பயனாளிகளுக்கு மாதம் **₹1,500** வழங்கப்படும்.
* இத்திட்டம் தற்போது திறந்துள்ளது; விண்ணப்பிக்க கடைசி தேதி இல்லை.

## தகுதி விதிகள் மற்றும் தேவையான ஆவணங்கள்

| விவரம் | விதி / ஆவணம் | நிலை |
|---|---|---|
| வயது | 60 வயது அல்லது அதற்கு மேல் | கட்டாயம் |
| ஆண்டு குடும்ப வருமானம் | ₹1,50,000 அல்லது அதற்குக் குறைவு (`CIR-2026-01` மூலம் 2026-09-10 முதல் ₹1,20,000-லிருந்து உயர்த்தப்பட்டது) | கட்டாயம் |
| அடையாளம் மற்றும் வயதுச் சான்று | ஆதார் அட்டை அல்லது செல்லுபடியாகும் வயதுச் சான்றிதழ் | கட்டாயம் |
| வருமானச் சான்றிதழ் | தகுதியான அதிகாரி வழங்கிய செல்லுபடியாகும் வருமானச் சான்றிதழ் | கட்டாயம் |
| இருப்பிடச் சான்று | மித்ரபூர் பிரதேச இருப்பிடச் சான்றிதழ் | கட்டாயம் |
| வங்கி பாஸ்புக் | செயல்பாட்டில் உள்ள வங்கிக் கணக்கு நகல் | கட்டாயம் |
| புகைப்படம் | சமீபத்திய பாஸ்போர்ட் அளவு புகைப்படம் | கட்டாயம் |

## விண்ணப்பம் மற்றும் இறுதி முடிவு
* `POL-FEE-01` கொள்கையின்படி விண்ணப்பிக்கக் கட்டணம் எதுவும் இல்லை (₹0).
* விண்ணப்பித்தவுடன் தானியங்கி ஒப்புதல் கிடைக்காது. ஆவணங்களைச் சரிபார்த்த பிறகு சம்பந்தப்பட்ட துறையே இறுதி முடிவை எடுக்கும்.
